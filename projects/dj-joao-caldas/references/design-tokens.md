# Design tokens

No final brand system has been supplied yet. The first implementation should
define a restrained, accessible token set in the application after inspecting
any approved visual references.

Minimum decisions to record before styling:

- text and muted-text contrast;
- surface and border roles;
- action and focus colors;
- display, heading, body, and label typography;
- spacing and content-width scale;
- image aspect-ratio and crop rules;
- reduced-motion behavior.

Do not infer a brand palette, logo treatment, or visual claims from the source
classified listing without owner review.
