# REVIEW workflow

1. Load objective, profile, baseline and changed paths.
2. Work read-only with fresh context.
3. Trace contracts, callers, persistence, dynamic references, tests and rollback.
4. Report prioritized evidence packets and uncertainty.
5. Return `GO`, `GO_WITH_FIXES`, `NO_GO` or `REVIEW_REQUIRED`.

Do not convert a tool finding into deletion or approval without corroboration.
