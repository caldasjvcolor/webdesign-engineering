# Context management

## Purpose

Reduce context load without compressing away uncertainty or losing the evidence
needed to resume work.

## When to use

Use in long tasks, large repositories, multi-agent work or repeated validation.

## When not to use

Skip for a tiny local task. Do not use summaries as a replacement for primary
evidence when a claim is material or disputed.

## Inputs

Goal, repository profile, current task/campaign capsule, structural map,
evidence packets and unresolved findings.

## Process

Route from goal to profile, map, search, exact span and task capsule; retrieve
just in time; return compact evidence packets; revalidate only the affected delta
after changes; retire resolved context and persist durable facts.

## Evidence

The capsule preserves baseline, uncertainty, risks, blockers, freshness and next action.

## Done criteria

Another agent can resume from durable evidence without the transcript.

## Stop / escalation conditions

Expand context or escalate when a material claim cannot be supported from the
current evidence.
