# Engineering harness routing

For non-trivial engineering work:

1. Read `.engineering/PROFILE.md` for project authority, validation and safety.
2. Read `.engineering/TASK.md`; for multi-phase work also read
   `.engineering/CAMPAIGN.md`.
3. Load only the optional Skills and workflows relevant to the current task.
4. Repository evidence overrides persisted summaries; keep uncertainty explicit.

## Merge strategy

If the repository has no root `AGENTS.md`, this file may be copied there. If one
already exists, preserve it and merge only this routing block, resolving any
conflict in favor of the repository's project-specific instructions. Never
overwrite an existing root `AGENTS.md` automatically.
